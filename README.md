# Minimalist Street Racer

A minimal, single-player street-racing web game built with React and Vite.

## Game Features
- **3-Track System:** Dodge obstacles across three separate lanes.
- **Dynamic Speed:** Configure the speed of the incoming obstacles on the fly.
- **Metrics Dashboard:** Real-time tracking for distance covered, total crashes, time elapsed, and dynamic score.

## How to Play
1. **Start the server:** Run `npm run dev` in the terminal to start the development server.
2. **Open the game:** Visit [http://localhost:5173](http://localhost:5173) in your web browser.
3. **Controls:** 
   - Click inside the game window to ensure it has keyboard focus.
   - Use the **Left Arrow** and **Right Arrow** keys on your keyboard to switch lanes.
   - Use the buttons at the bottom left to increase or decrease the speed.

## Installation
If you haven't already, install the project dependencies:
```bash
npm install
```
